# 학생 진로 통합 지원 흐름

## 학생

- 로그인 입력란에서 Enter로 로그인할 수 있습니다.
- 상단 또는 왼쪽의 자신의 이름을 눌러 진로·관심사·이름을 저장하고 통합 계정 비밀번호를 변경합니다. 비밀번호는 문학·문법 사이트에도 함께 적용됩니다.
- `개별 탐구 과제 작성`은 교사의 배포 양식이 없어도 사용할 수 있습니다. 배포받은 과제는 별도의 활동지 목록에서 선택합니다.
- `나의 결과물`에서 답변을 수정하고, 첨부파일과 교사 피드백을 확인합니다. 첨부파일 내용은 자동 분석하지 않으며 작성한 답변을 분석합니다.
- `진로 탐색`의 `진로 심화활동 제안`에서 이유·방법·결과물을 확인하고 제안으로 새 과제를 시작합니다. 추천 문장은 초안이므로 실제 계획에 맞게 수정합니다.
- 작성·수정할 때 이전 활동을 선택하면 연결이 저장됩니다. 다른 학생의 기록, 자기 자신, 순환하는 관계는 연결할 수 없습니다.

## 교사

- 기본 메뉴는 학생 활동 / 활동지·배포 / 프로젝트·그룹 / 활동 연결 지도 / 공지사항 / AI 활용 안내입니다.
- 최근 활동 제목으로 답변과 첨부파일을 열고 직접 피드백을 저장합니다. 이름을 누르면 학생의 누적 결과물과 연결 지도를 확인합니다.
- 프로젝트 신청자를 개별 선발하거나 그룹에 속한 신청자를 일괄 선발할 수 있습니다. 활동지에서 프로젝트와 배포 대상을 지정합니다.
- 활동지의 5개 분류는 공통 과제, 진로 탐색 과제, 심화 탐구 과제, 프로젝트 과제, 개별 탐구 과제입니다. 전체·개별·그룹 배포를 지원합니다.
- 학생화면 버튼을 누른 경우에만 학생 메뉴로 전환합니다. 이 화면은 교사 본인 계정의 기록을 사용하며 학생을 사칭하지 않습니다.
- 공개 공지와 전체 공개 활동지는 비로그인 상태에서 조회할 수 있습니다. 개별·그룹 배포 대상 정보는 공개하지 않습니다.

## 분석의 의미와 한계

외부 AI가 아닌 기본 규칙 분석입니다. 현재 진로 분야의 고유 개념(최대 45), 탐구 과정(25), 근거(20), 성찰 표현(10)을 서로 다른 용어 기준으로 집계합니다. 같은 단어 반복이나 글자 수 증가로 점수를 추가하지 않습니다. 구체적인 문장 최소 기준을 충족하지 못하면 0점/분석 불가입니다. 문맥의 진실성·수준까지 판단하지 않으며 대학 입학 가능성, 학생 능력, 전공 적합성의 확정 평가가 아닙니다.

연결 지도 실선은 작성자가 지정한 관계, 점선은 현재 진로의 공통 개념이 2개 이상인 기록을 연결한 추정입니다. 점선은 탐구의 인과관계를 입증하지 않습니다. 진로 변경 시 기존 답변도 현재 진로 기준으로 다시 계산합니다.

## Gemini 무료 API 검토

2026-09-20에 확인한 [Gemini API 이용 조건](https://ai.google.dev/gemini-api/terms)은 18세 미만 사용 가능성이 있는 웹사이트/API 클라이언트에 대한 제한을 명시합니다. 무료 서비스 입력·출력이 제품 개선 등에 활용될 수 있으므로 학생 보고서나 개인정보를 외부로 보내는 연동을 활성화하지 않았습니다. 유료 전환만으로 연령 제한이 해결된다고 가정하지 않습니다.

대안은 성인 교사가 별도 환경에서 개인정보 없는 공통 전공별 질문·평가 기준을 생성하고 검토한 뒤 활동지 문항으로 활용하는 것입니다. 한 번 생성한 자료를 저장·재사용해 호출을 줄이며, 고정 무료량을 보장하지 않고 [요금](https://ai.google.dev/gemini-api/docs/pricing)과 [호출 한도](https://ai.google.dev/gemini-api/docs/rate-limits)를 확인합니다. 사이트에는 API 키를 입력하거나 학생 데이터를 전송하는 경로가 없습니다.

## 배포

기존 Synology 자동 배포를 유지합니다. 추가 마이그레이션 `0004`는 기존 기록을 지우지 않고 피드백, 연결 정보, 제출 당시 문항을 보관할 열을 추가합니다. 과거 기록은 문항 보관 정보가 없으므로 현재 양식 및 원래 답변 키를 이용해 누락 없이 표시합니다. 학생이 답변을 수정해도 교사 피드백은 유지됩니다.
