# 반복 운영하는 탐구 프로젝트

로그인 후 첫 화면과 왼쪽 메뉴에서 **탐구 프로젝트**(학생), **탐구 프로젝트 운영**(교사)을 엽니다. 기존 개별 과제와 진로 포트폴리오는 기존 메뉴에서 계속 사용할 수 있습니다.

## 교사의 시작 순서

1. 프로젝트를 만들고 주제와 설명을 입력합니다. 기존 모집 프로젝트에 단계형 활동을 연결할 수도 있습니다.
2. 여섯 단계의 안내와 마감일을 수업에 맞게 수정합니다. 특정 과학기술 주제로 제한하지 않으며, 물리·생명과학·화학 외의 관점도 주제에 맞게 안내할 수 있습니다.
3. 신청한 학생을 선발한 뒤 프로젝트 안에서 모둠과 대표 학생을 지정합니다. 한 학생은 한 프로젝트에서 한 모둠에 속합니다.
4. 진행표에서 모둠과 단계를 눌러 답변을 확인합니다. 피드백을 남기며 **보완 요청** 또는 **확인 완료**를 선택합니다. 이전 피드백도 보관됩니다.
5. 모집 마감은 신규 신청을 막고, 보관 처리는 프로젝트 작성·토론·피드백을 종료합니다. 기존 결과는 조회할 수 있습니다.

## 학생의 활동 순서

| 단계 | 남길 내용 |
| --- | --- |
| 미디어 주장 수집 | 검증할 주장, 원문 링크, 제작자·발표 시기·목적 |
| 과학적 검증 | 출처를 포함한 근거, 분야별 관점, 한계 |
| 사실 판단 | 판단 범주, 근거에 따른 이유, 판단이 달라질 조건 |
| 모둠 토론 | 질문·반론·추가 근거, 받은 의견에 대한 답변, 보완한 생각 |
| 결과물 제출 | 팩트체크 보고서, 디지털 콘텐츠, 시민 제안서와 첨부파일 |
| 개인 성찰 | 본인의 기여, 관점 변화, 진로 연결, 후속 탐구 계획 |

모둠 대표가 공동 답변을 저장·제출하고 모둠원은 확인하고 토론에 참여합니다. 개인 성찰은 각자 작성합니다. 임시저장은 일부 문항만 작성해도 가능하며, 제출할 때 필수 문항을 확인합니다. 앞 단계를 제출하면 다음 단계 제출이 가능하여 교사 확인을 기다리는 동안에도 탐구를 이어갈 수 있습니다. 보완 요청은 다음 할 일에 다시 표시됩니다.

작성 안내는 현재 단계, 빈 문항, 교사 피드백과 설정한 진로에 따른 규칙 기반 코칭입니다. 주장의 진실성을 자동 판정하거나 학생 능력을 점수화하지 않습니다. 최종 사실 판단과 출처 검토는 학생과 교사가 수행합니다. 개인 성찰에서 후속 탐구를 시작하면 기존 개별 탐구 과제 작성 화면으로 연결됩니다.

## 공개와 기록 보관

- 모집 목록에는 프로젝트 설명과 본인의 신청·선발 상태가 표시됩니다.
- 작업 공간과 토론은 현재 선발된 참가 학생과 교사만 접근합니다.
- 모둠 임시저장은 현재 모둠원과 교사, 제출한 모둠 활동은 프로젝트 참가자에게 공개됩니다.
- 개인 성찰과 첨부파일은 본인과 교사만 조회합니다. 기존 개인 보고서는 프로젝트 참가자에게 공개되지 않습니다.
- 첨부파일은 단계별 1개, 최대 20 MB입니다. 여러 결과물은 링크를 함께 기록하거나 묶어서 첨부할 수 있습니다.
- 같은 기록을 두 화면에서 고치면 먼저 저장한 내용을 덮어쓰지 않도록 충돌을 알립니다. 다시 불러오기 전 작성 내용을 따로 보관하세요.

## 운영자 참고

기존 프로젝트·회원 데이터와 연결된 별도 단계·모둠·답변·토론 테이블을 추가합니다. 기존 활동 데이터는 유지합니다. NAS 시작 시 추가 마이그레이션을 실행하며 성공한 경우에만 스키마 마커를 기록합니다. 테스트는 로컬 가상 계정과 별도 저장소에서 실행하며 운영 학생 계정이나 보고서를 테스트에 사용하지 않습니다.
