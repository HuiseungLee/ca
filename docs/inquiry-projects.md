# 반복 운영하는 탐구 프로젝트

로그인 후 첫 화면과 왼쪽 메뉴에서 **탐구 프로젝트**(학생), **탐구 프로젝트 운영**(교사)을 엽니다. 기존 개별 과제와 진로 포트폴리오는 기존 메뉴에서 계속 사용할 수 있습니다.

## 교사의 시작 순서

1. 프로젝트를 만들고 주제와 설명을 입력합니다. 기존 모집 프로젝트에 단계형 활동을 연결할 수도 있습니다.
2. **활동지 편집·배포**에서 단계를 골라 문항과 응답 형식을 편집합니다. 새 융합탐구 프로젝트는 **문항 저장**으로 질문을 준비하고, 별도의 **배부와 진행 관리**에서 실제 작성 시기를 엽니다. 팩트체크 프로젝트는 기존 **문항 저장·배포** 방식을 유지합니다. 단계 안내와 마감일은 **운영 설정**에서 수정합니다. 주제는 특정 과학기술 분야로 제한하지 않습니다.
3. **운영 설정 → 참가 신청과 선발** 및 모둠 구성에서 신청 학생의 참가 권한과 모둠을 관리합니다. 새 융합탐구에서는 신청서가 배부된 뒤 모둠장이 직접 본인의 모둠을 만들어 신청서를 시작할 수 있습니다. 일반 모둠원은 참가 신청 후 교사가 배정합니다. 한 학생은 한 프로젝트에서 한 모둠에 속합니다.
4. 진행표에서 모둠과 단계를 눌러 답변을 확인합니다. 피드백을 남기며 **보완 요청** 또는 **확인 완료**를 선택합니다. 이전 피드백도 보관됩니다.
5. 모집 마감은 신규 신청을 막고, 보관 처리는 프로젝트 작성·토론·피드백을 종료합니다. 기존 결과는 조회할 수 있습니다.

## 학생의 활동 순서 (팩트체크 6단계)

아래 문항 구성은 처음 프로젝트를 만들 때 제공되는 기본 양식입니다. 일반 **활동지·배포** 메뉴의 양식을 가져오는 방식이 아니라, 프로젝트마다 각 단계의 양식을 독립적으로 관리합니다.

| 단계             | 남길 내용                                               |
| ---------------- | ------------------------------------------------------- |
| 미디어 주장 수집 | 검증할 주장, 원문 링크, 제작자·발표 시기·목적           |
| 과학적 검증      | 출처를 포함한 근거, 분야별 관점, 한계                   |
| 사실 판단        | 판단 범주, 근거에 따른 이유, 판단이 달라질 조건         |
| 모둠 토론        | 질문·반론·추가 근거, 받은 의견에 대한 답변, 보완한 생각 |
| 결과물 제출      | 팩트체크 보고서, 디지털 콘텐츠, 시민 제안서와 첨부파일  |
| 개인 성찰        | 본인의 기여, 관점 변화, 진로 연결, 후속 탐구 계획       |

모둠 대표가 공동 답변을 저장·제출하고 모둠원은 확인하고 토론에 참여합니다. 개인 성찰은 각자 작성합니다. 임시저장은 일부 문항만 작성해도 가능하며, 제출할 때 필수 문항을 확인합니다. 앞 단계를 제출하면 다음 단계 제출이 가능하여 교사 확인을 기다리는 동안에도 탐구를 이어갈 수 있습니다. 보완 요청은 다음 할 일에 다시 표시됩니다.

제출할 때 필수 응답, 선택지, 출처 주소를 확인합니다. 출처 문항에는 `http://` 또는 `https://`로 시작하는 주소를 한 줄에 하나씩 적습니다. 오류가 있으면 해당 문항과 저장 버튼 가까이에 안내하며 입력한 답변은 유지합니다. 주소를 아직 찾지 못했거나 작성 중이라면 임시저장할 수 있습니다. 제출에 성공하면 같은 위치에 완료 안내와 다음 단계 버튼이 표시됩니다.

두 번째 단계부터 **이전 기록 보며 작성하기**에서 앞서 진행한 모든 단계 중 하나를 골라 참고합니다. 큰 화면에서는 작성란 오른쪽, 좁은 화면에서는 작성란 위에 표시됩니다. 바로 앞 단계가 기본 선택되며, 이전 답변·문항·출처·첨부파일을 참고해도 현재 작성 중인 내용은 바뀌지 않습니다. 아직 저장한 기록이 없다면 기록 없음으로 표시됩니다.

작성 안내는 현재 단계, 빈 문항, 교사 피드백과 설정한 진로에 따른 규칙 기반 코칭입니다. 주장의 진실성을 자동 판정하거나 학생 능력을 점수화하지 않습니다. 최종 사실 판단과 출처 검토는 학생과 교사가 수행합니다. 개인 성찰에서 후속 탐구를 시작하면 기존 개별 탐구 과제 작성 화면으로 연결됩니다.

## 단계별 활동지 편집과 배포

- 위치: **탐구 프로젝트 운영 → 프로젝트 열기 → 활동지 편집·배포**. 기록 화면의 **이 단계 문항 편집**으로도 바로 들어갑니다.
- 문항은 단계마다 1~20개이며 추가·삭제·순서 변경, 질문·도움말·필수 여부 수정이 가능합니다. 응답 형식은 짧은 답변, 긴 답변, 선택형, 출처 링크, 물품 신청 표입니다. 선택형 보기 역시 편집할 수 있습니다.
- 편집 중인 내용은 미리보기로 확인합니다. 팩트체크는 **문항 저장·배포**, 배부 관리형 융합탐구는 **문항 저장**을 누르기 전까지 학생 양식이 바뀌지 않습니다. 융합탐구에서는 문항을 저장해도 미배부 단계를 자동으로 열지 않습니다. 작성 대상은 해당 프로젝트에 참가 권한이 있는 학생이며, 공동 기록은 모둠장이, 성찰은 각자가 작성합니다.
- 변경된 양식은 해당 단계를 아직 저장하지 않은 모둠·학생의 새 기록에 적용됩니다. 처음 임시저장한 시점의 문항과 버전을 답변과 함께 보관하므로, 이미 시작한 기록은 문항을 삭제하거나 바꾸어도 내용이 사라지지 않습니다.
- 배포 전에 열어둔 오래된 화면으로 첫 저장을 시도하면 최신 양식을 다시 불러오도록 안내합니다. 두 교사가 동시에 배포하는 경우에도 먼저 배포된 문항을 덮어쓰지 않습니다.
- 기존 버전에서 작성한 기록은 당시의 기본 문항으로 표시·수정됩니다. 단계 안내의 당시 내용도 기록과 함께 유지합니다.

## 공개와 기록 보관

- 모집 목록에는 프로젝트 설명과 본인의 신청·선발 상태가 표시됩니다.
- 작업 공간과 토론은 현재 선발된 참가 학생과 교사만 접근합니다.
- 팩트체크 프로젝트의 모둠 임시저장은 현재 모둠원과 교사, 제출한 모둠 활동은 프로젝트 참가자에게 공개됩니다. 융합탐구 프로젝트의 공동 기록은 제출 후에도 해당 모둠원과 교사만 볼 수 있습니다.
- 개인 성찰과 첨부파일은 본인과 교사만 조회합니다. 기존 개인 보고서는 프로젝트 참가자에게 공개되지 않습니다.
- 첨부파일은 단계별 1개, 최대 20 MB입니다. 여러 결과물은 링크를 함께 기록하거나 묶어서 첨부할 수 있습니다.
- 같은 기록을 두 화면에서 고치면 먼저 저장한 내용을 덮어쓰지 않도록 충돌을 알립니다. 다시 불러오기 전 작성 내용을 따로 보관하세요.

## 운영자 참고

기존 프로젝트·회원 데이터와 연결된 별도 단계·모둠·답변·토론 테이블을 추가합니다. 기존 활동 데이터는 유지합니다. NAS 시작 시 추가 마이그레이션을 실행하며 성공한 경우에만 스키마 마커를 기록합니다. 테스트는 로컬 가상 계정과 별도 저장소에서 실행하며 운영 학생 계정이나 보고서를 테스트에 사용하지 않습니다.

## 융합탐구: 계획서부터 개인 성찰까지

교사가 **탐구 프로젝트 운영 → 프로젝트 만들기 → 융합탐구(계획서·물품·보고서·성찰)**를 선택하면 다음 네 양식으로 진행하는 별도 프로젝트를 만듭니다. 기존 6단계 미디어 팩트체크 프로젝트의 양식이나 작성 기록은 바뀌지 않습니다.

| 순서 | 양식                                   | 작성·제출 담당    | 작성 시점 |
| ---- | -------------------------------------- | ----------------- | --------- |
| 1    | 융합탐구 프로젝트 활동 계획서          | 모둠장            | 활동 전   |
| 2    | 융합탐구 프로젝트 물품 신청서          | 모둠장            | 활동 전   |
| 3    | 융합탐구 프로젝트 탐구확장 심화 보고서 | 모둠장            | 활동 후   |
| 4    | 융합탐구 프로젝트 성찰 일지            | 모둠원 전원, 각자 | 활동 후   |

새 프로젝트는 네 양식 모두 **미배부** 상태로 시작합니다. 다음 순서로 운영합니다.

1. 교사는 양식을 편집한 뒤 프로젝트의 **배부와 진행 관리**에서 활동 전 신청 양식(활동 계획서·물품 신청서)을 배부합니다.
2. 가입·로그인한 모둠장은 프로젝트 목록에서 모둠명을 입력하고 **모둠장 · 신청서 작성 시작**을 누릅니다. 본인만 포함된 모둠과 신청서 작업 공간이 만들어집니다. 다른 학생을 임의로 등록할 수는 없습니다. 일반 모둠원은 **모둠원 · 참가 신청**을 누르고 교사가 **운영 설정 → 참가 신청과 선발**에서 참가 권한을 부여한 뒤 모둠 구성에서 배정합니다. 교사가 미리 모둠을 구성하는 방식도 가능합니다.
3. 모둠장은 계획서와 물품 신청서를 작성·제출합니다. 두 양식은 독립적으로 제출할 수 있으므로 물품 신청서가 계획서 제출을 기다리지 않습니다.
4. 교사는 각 양식을 확인하고 **확인 완료**로 승인하거나 **보완 요청**으로 피드백합니다. 두 신청 양식 모두 확인 완료인 모둠을 기준으로 실제 활동을 안내합니다. 작업 공간 참가 권한은 신청서 승인과 별개입니다.
5. 실제 활동 후 교사는 **배부와 진행 관리**에서 활동 후 양식(탐구확장 심화 보고서·성찰 일지)을 별도로 배부합니다. 배부되어 있어도 해당 모둠의 두 신청 양식이 확인 완료가 아니면 활동 후 양식의 작성·첨부가 제한됩니다.
6. 모둠장은 보고서를 제출하고, 모둠장 포함 모든 학생은 본인의 성찰을 제출합니다. 성찰 일지는 모둠장 보고서 제출을 기다리지 않고 작성·제출할 수 있습니다.
7. 교사와 학생은 **기록 내려받기** 또는 개별 기록의 내려받기 버튼에서 저장된 신청서·보고서·성찰을 파일로 보관합니다.

모둠원은 같은 모둠의 계획서·물품 신청서·보고서를 참고할 수 있지만 공동 기록의 저장·제출은 모둠장만 가능합니다. 성찰 일지는 모둠장도 포함하여 각자 작성하며, 다른 학생의 성찰은 볼 수 없습니다. 교사는 모든 모둠의 기록과 각 학생의 성찰에 피드백을 남깁니다.

활동 계획서에는 탐구회원 정보, 진로 희망 분야, 관심 키워드, 관련 교과목과 선정 계기, 주제, 방법, 기대 효과를 적습니다. 보고서에는 과정과 결과, 교과 내용과의 관련성, 흥미·새롭게 알게 된 점, 실생활·사회적 기여, 후속 탐구 계획을 적습니다. 성찰 일지는 학번·성명, 참여 동기, 본인의 역할, 새롭게 알게 된 점, 아쉬운 점, 성찰을 기록합니다. 학년도·작성일 등 양식에 마련된 정보를 실제 활동에 맞게 입력하세요.

물품 신청서는 물품명·모델명, 규격, S2B 물품번호, 수량, 단가, 배송비를 행별로 작성합니다. 행을 추가하거나 삭제할 수 있으며, 신청액은 **수량 × 단가 + 배송비**, 합계는 모든 행의 신청액을 합산합니다. **배송비를 포함한 총액이 200,000원 이하**여야 제출할 수 있습니다. 수량은 양의 정수, 단가와 배송비는 0원 이상의 정수로 적습니다. 신청할 물품이 없을 때는 **신청 물품 없음**으로 제출하면 다음 활동을 진행할 수 있습니다. 이 신청은 교사의 검토를 위한 기록이며 실제 구매나 결제를 실행하지 않습니다.

일부만 입력한 상태에서는 임시저장해 두고 이어 쓸 수 있습니다. 다음 단계의 **이전 기록 보며 작성하기**에서 계획서와 앞선 신청·보고 내용을 참고할 수 있습니다. 공동 기록도 다른 모둠에는 공개되지 않으며, 해당 모둠과 교사만 볼 수 있습니다.

각 단계의 질문과 안내는 기존과 같이 **활동지 편집·배포**에서 프로젝트별로 조정합니다. 이미 임시저장하거나 제출한 답변은 당시 문항을 유지합니다. 물품 표의 수량·금액 검증과 예산 한도는 학생이 문항을 우회하여 제출할 수 없도록 서버에서도 확인합니다.

### 배부 회수와 기존 프로젝트

- 배부를 회수하면 해당 단계의 새 작성·수정·첨부를 막습니다. 이미 저장한 답변·교사 피드백·첨부는 삭제하지 않으며 기존 접근 권한 안에서 조회·다운로드할 수 있습니다.
- 확인 완료된 신청서를 학생이 수정하면 다시 확인이 필요합니다. 두 신청 양식이 다시 확인 완료되기 전까지 보고서·성찰의 새 작성·수정·첨부가 제한됩니다. 이미 저장된 보고서·성찰은 유지됩니다.
- 모집 마감은 새 모둠의 신청을 막습니다. 프로젝트 보관은 작성과 배부 변경을 종료하며 기존 기록은 내려받을 수 있습니다.
- 이전에 만든 융합탐구 프로젝트는 갑자기 잠기지 않도록 기존 공개 상태와 단계 순서를 유지합니다. 교사가 배부 관리 버튼으로 명시적으로 전환한 뒤부터 위 배부 관리 규칙을 적용합니다. 기존 팩트체크 6단계는 변경하지 않습니다.

### 기록 내려받기

- 현재 제공하는 형식은 **DOCX 문서, XLSX 엑셀 파일, CSV**입니다. HWP와 구형 XLS 원본 형식은 제공하지 않으며, 다른 파일에 해당 확장자만 붙여 내려보내지 않습니다.
- 교사는 전체 기록 또는 개별 기록을, 학생은 본인 모둠의 공동 기록과 본인의 성찰을 내려받습니다. 다른 학생의 개인 성찰은 포함되지 않습니다.
- 내려받는 내용은 **저장된 답변**이며 아직 저장하지 않은 화면 입력값은 포함되지 않습니다. 작성 당시의 문항·문항 버전·작성자 정보·제출 상태·교사 피드백을 함께 보관합니다. 물품 신청서는 행별 수량·단가·배송비와 합계를 포함합니다.
- 첨부파일은 문서에 삽입하지 않고 파일명만 기록합니다. 실제 첨부파일은 해당 단계의 첨부 다운로드를 이용합니다.
- CSV는 한글 인코딩 표식과 따옴표 처리를 적용하고, 학생이 입력한 수식 형태의 값이 실행되지 않도록 안전한 텍스트로 내보냅니다. XLSX도 학생 답변을 수식이 아닌 텍스트로 저장합니다.
